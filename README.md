# Employee Attrition Prediction - HR Analytics

> Predict which employees are likely to leave using Machine Learning

### 🎯 Problem
Company ge 1 employee leave aadre 1.5L loss. This model predicts attrition with 87% accuracy.

### 🛠️ Tech Stack
- Python, Pandas, NumPy
- Scikit-learn, Matplotlib, Seaborn
- Models: Random Forest, Logistic Regression

### 📊 What I Did
1. EDA on 35 features (IBM HR Dataset)
2. Handled imbalance with SMOTE
3. Trained models - Best: Random Forest (87% Accuracy)
4. Key Insight: Overtime + Low Job Satisfaction = High Attrition

### 📈 Results
- Accuracy: 87.3%
- Top Factors: OverTime, JobSatisfaction, MonthlyIncome

### 🚀 How to Run
pip install -r requirements.txt
python employee_attrition_prediction.py
